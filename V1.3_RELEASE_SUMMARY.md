## 🆕 **New Features in V1.3**

### 1. 📺 **URL Video Processing**
Download and analyze videos from URLs without manual upload.

**Features**:
- ✅ YouTube video downloads (all qualities)
- ✅ Direct URL downloads (MP4, MOV, AVI, MKV)
- ✅ Background processing
- ✅ Progress tracking
- ✅ Quality selection (360p - 1080p)

**Endpoints**:
```
POST /api/url/download - Download video from URL
GET  /api/url/status/{project_id} - Check download status
GET  /api/url/supported-sites - List supported sites
```

**Use Cases**:
- Analyze YouTube videos
- Process videos from cloud storage
- Batch analyze online content
- No manual download needed

---

### 2. 📦 **Batch Video Processing**
Upload and process multiple videos simultaneously.

**Features**:
- ✅ Upload up to 10 videos at once
- ✅ Parallel processing
- ✅ Individual project creation
- ✅ Batch status tracking
- ✅ Error handling per video

**Endpoints**:
```
POST   /api/batch/upload - Upload multiple videos
GET    /api/batch/status/{batch_id} - Check batch status
GET    /api/batch/list - List all batch jobs
DELETE /api/batch/{batch_id} - Delete batch job
```

**Use Cases**:
- Process surveillance footage
- Analyze multiple camera feeds
- Bulk video analysis
- Time-saving workflows

---

### 3. 🔍 **Video Comparison**
Compare multiple videos side-by-side with AI insights.

**Features**:
- ✅ Compare 2-5 videos
- ✅ Object detection comparison
- ✅ Activity analysis comparison
- ✅ Anomaly comparison
- ✅ AI-generated insights
- ✅ Recommendations

**Endpoints**:
```
POST /api/compare - Compare videos
GET  /api/compare/{comparison_id} - Get comparison result
GET  /api/compare/templates - Get comparison templates
```

**Comparison Types**:
- **Objects**: Compare detected objects
- **Activities**: Compare events and activities
- **Anomalies**: Compare anomalies
- **All**: Comprehensive comparison

**Use Cases**:
- Compare before/after scenarios
- Multi-camera analysis
- Performance benchmarking
- Quality comparison

---

### 4. 🔐 **API Key Management**
Secure storage and management of user API keys.

**Features**:
- ✅ Encrypted storage (Fernet encryption)
- ✅ Multiple service support
- ✅ Key masking for security
- ✅ Active/inactive toggle
- ✅ Last used tracking
- ✅ CRUD operations

**Supported Services**:
- OpenRouter
- OpenAI
- Anthropic (Claude)
- Hugging Face
- Replicate

**Endpoints**:
```
POST   /api/keys - Create API key
GET    /api/keys - List all keys
GET    /api/keys/{key_id} - Get specific key
PATCH  /api/keys/{key_id} - Update key
DELETE /api/keys/{key_id} - Delete key
GET    /api/keys/service/{service_name} - Get key for service
GET    /api/services/supported - List supported services
```

**Security**:
- Encryption at rest
- Masked display
- Secure retrieval
- User isolation
